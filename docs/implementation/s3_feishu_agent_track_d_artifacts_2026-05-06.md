# S3 Feishu Agent Track D Artifacts 2026-05-06

## Scope

Integrate Track D artifact generation into the existing LLM-driven `feishu_agent` route.

This does not introduce a deterministic workflow mode. `classic_s3` and `feishu_agent` remain the only user-facing runtime modes.

## Current State

- `feishu_agent` runs `AgentS3 + WindowsFeishuACI`.
- Track D has `ReportBuilder` and `ArtifactManager`.
- Track D artifacts were previously produced by a deterministic worker path, but that path has been deleted. Artifacts are now generated by `S3RuntimeRecorder`.
- The S3 loop in `gui_agents/s3/cli_app.py` executes LLM-generated code but does not emit structured run artifacts.

## Design

Add a small Track D recorder that consumes runtime facts from the S3 loop:

- instruction
- step index
- screenshots already captured by the S3 loop
- generated action code
- execution status
- failure reason if execution fails or the model returns fail

The recorder writes a `RuntimeContext` through the existing `ReportBuilder`.

The recorder must not:

- parse the instruction into a deterministic `TestCase`
- call Track C workflows
- decide the next action
- change how `AgentS3.predict()` works

## Manual Plan

Target files:

- Track D recorder module.
- Existing CLI S3 loop.
- Track D tests.

Depends on:

- `ReportBuilder`
- `ArtifactManager`
- existing S3 `run_agent()` observation and action execution loop

Outputs:

- `artifacts/test_runs/<run_id>/summary.json`
- `artifacts/test_runs/<run_id>/report.md`
- `artifacts/test_runs/<run_id>/actions.jsonl`
- optional per-step screenshots when the observation contains PNG bytes

Verification:

- recorder unit tests
- `tests.test_agent_startup`
- shared local/GitHub check runner

Risks:

1. The S3 route has no deterministic verifier.
   Mitigation: mark executed actions as runtime-passed only when `exec()` completes; keep assertions empty.

2. Artifact writing could fail during a live run.
   Mitigation: failures are reported as warnings and must not take control away from the LLM loop.

3. Screenshot artifacts can grow.
   Mitigation: store only one screenshot per observed step.
