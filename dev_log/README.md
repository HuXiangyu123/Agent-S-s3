# 开发日志规范

## 文件命名

```
dev_log/YYYY-MM-DD_<简短标识>.md
```

示例：`dev_log/2026-05-04_baseline.md`

## 日志格式

每篇日志包含以下章节：

```markdown
# <标题> — YYYY-MM-DD

## 背景
- 本次开发的出发点和目标

## 变更清单
| 文件 | 操作 | 说明 |
|------|------|------|

## 关键决策
- 决策 1 + 理由
- 决策 2 + 理由

## 验证
- [ ] 检查项 1
- [ ] 检查项 2

## 风险 & 后续
- 已知风险
- 下一步计划
```

## 维护规则

- 每次有意义的改动后更新或新增日志
- 不记录琐碎的 lint/格式修改
- 如果一次会话包含多个独立改动，拆分为多篇日志
- 每篇日志对应一个或多个 git commit
